# Shopthai2026-PRO Patch04 — เลือกสินค้าทำคลิปจากคลิก

## ติดตั้ง (ยังไม่ได้แก้เว็บจริง)
1. สำรอง `admin.html`, `assets/app.js` และฐานข้อมูลก่อน
2. ติดตั้ง Patch03 ให้เรียบร้อยก่อน: ตาราง `affiliate_click_events` และฟังก์ชันบันทึกคลิกต้องมีอยู่
3. เปิด Supabase SQL Editor ตรวจทานและรัน `sql/02_promotion_recommendations.sql` (เพิ่ม/แทนที่ RPC อ่านอย่างเดียว ไม่แก้ข้อมูลคลิกเดิม)
4. ใน branch ทดสอบของ GitHub วาง `admin.html` ที่ root และ `assets/app.js` ใน `assets/` โดยคง `assets/config.js` เดิมไว้
5. เข้าระบบ Admin → เมนู "แนะนำสินค้าโปรโมต" → กดอัปเดตคำแนะนำ

## กฎทดลอง
- ดูยอดคลิก 30 วันและ 7 วัน; คะแนน = คลิก 30 วันหลังตัดช่วงพุ่ง + 2 × min(คลิก 7 วัน, 100)
- นาทีใดที่สินค้าหนึ่งถูกคลิกตั้งแต่ 10 ครั้ง จะถือเป็นช่วงพุ่งและตัดคลิกทั้งหมดในนาทีนั้นออกจากคะแนน
- หากมีช่วงพุ่งหรือคลิกจากช่วงพุ่ง >= 30% ให้พักตรวจสอบ ไม่แนะนำโปรโมต
- ถ้าคลิกหลังตัดช่วงพุ่ง >= 10 และคลิก 7 วัน >= 3 จึงแนะนำทำคลิป; นอกนั้นรอข้อมูลเพิ่ม
- เกณฑ์เหล่านี้เป็น heuristic ปรับได้หลังมีข้อมูลจริง และอาจทำให้สินค้าที่มีคนสนใจจริงถูกพักผิดพลาด

## ข้อจำกัดด้านบอต
Patch03 บันทึก event ผ่าน RPC สาธารณะโดยไม่ผูกกับผู้ชมที่ยืนยันตัวตน จึงไม่สามารถตรวจจับผู้ใช้คนเดิมข้ามอุปกรณ์ หรือกันบอตที่ส่งคลิกกระจายเวลาได้ Patch04 **ตรวจจับความผิดปกติและลดน้ำหนักคลิกเท่านั้น** ไม่ใช่ระบบป้องกันบอตอย่างสมบูรณ์ หากต้องการป้องกันจริงให้ใช้ Edge Function พร้อม rate limit ฝั่งเซิร์ฟเวอร์และ CAPTCHA/Turnstile (โดยพิจารณาความเป็นส่วนตัว) ในระยะถัดไป

ยอดคลิกไม่ใช่ยอดขายหรือค่าคอมมิชชัน Shopee; ไม่ได้มีการโพสต์คลิปอัตโนมัติ
