# Shopthai2026 PRO — คู่มือติดตั้งทีละขั้นตอน

**สถานะ:** ชุดโปรเจกต์ใหม่สำหรับทดลอง ยังไม่ได้อัปโหลดหรือเปลี่ยนเว็บไซต์เดิม `tummarat48.github.io/Shopthai2026/` และยังไม่ได้สร้าง Supabase project ในบัญชีของคุณ

## 1) ไฟล์ที่มี
- `index.html` หน้าแรก / สินค้าแนะนำ / โปรโมชั่น
- `categories.html` รายการหมวดหมู่
- `products.html` ค้นหาและกรองสินค้า
- `product.html` รายละเอียดสินค้าและลิงก์ Affiliate
- `cart.html` รายการที่สนใจ (เก็บในเบราว์เซอร์ ไม่ใช่ตะกร้าชำระเงิน)
- `admin.html` เข้าสู่ระบบและจัดการสินค้า หมวดหมู่ โปรโมชั่น รูป และ CSV
- `assets/config.js` ตั้งค่าการเชื่อมต่อ Supabase
- `assets/app.js`, `assets/style.css` โค้ดและรูปแบบเว็บไซต์
- `sql/setup.sql` ตาราง ฐานข้อมูล RLS และ Storage policy
- `data/initial-products.csv` สินค้าไม่ซ้ำ 20 รายการจากไฟล์ CSV 8 ชุด
- `data/initial-products.json` ข้อมูลเดียวกันในรูปแบบ JSON

## 2) สร้างโปรเจกต์ Supabase
1. สมัคร/เข้าสู่ระบบที่ https://supabase.com/dashboard
2. กด **New project** เลือกชื่อ `shopthai2026-pro` ตั้งรหัสผ่านฐานข้อมูลที่แข็งแรง และเลือก Region ใกล้ผู้ใช้
3. เปิด **SQL Editor → New query** วางเนื้อหาจาก `sql/setup.sql` และกด **Run** (ควรใช้กับโปรเจกต์ใหม่ที่ว่าง)
4. เปิด **Project Settings → API** หรือ **Connect** เพื่อคัดลอก **Project URL** และ **anon/publishable key**
5. แก้ `assets/config.js` โดยใส่ URL และ publishable/anon key จริง **ห้ามใส่ service_role หรือ secret key ในโค้ดหน้าเว็บ**

## 3) ตั้งค่า Auth และสร้างแอดมิน
1. ใน Supabase เปิด **Authentication → Providers → Email** เปิดการใช้ Email/Password
2. ปิด public signups หากต้องการให้เจ้าของร้านเท่านั้นมีบัญชี หรือใช้การเชิญบัญชีจาก Dashboard
3. ที่ **Authentication → Users** สร้าง/เชิญผู้ใช้แอดมิน และให้ผู้ใช้ตั้งรหัสผ่าน
4. คัดลอก `User UID` จากหน้าผู้ใช้ใน Supabase
5. ใน SQL Editor รัน (แทน UUID ด้วย UID จริง):

```sql
insert into public.admin_users (user_id)
values ('00000000-0000-0000-0000-000000000000')
on conflict (user_id) do nothing;
```

**หมายเหตุ:** คำสั่งนี้ใช้สิทธิ์ของเจ้าของโปรเจกต์ใน SQL Editor เท่านั้น อย่าเปิดช่องให้ผู้ใช้ทั่วไปเพิ่มตัวเองเป็นแอดมิน และอย่าใส่ UID ตัวอย่างโดยไม่เปลี่ยน

## 4) ตั้งค่าเว็บไซต์และทดลอง
1. เปิด `assets/config.js` กรอกค่าจริงตามข้อ 2
2. ใช้ VS Code Live Server หรือเปิด terminal ที่โฟลเดอร์โปรเจกต์แล้วรัน `python -m http.server 8000`
3. เปิด `http://localhost:8000/admin.html` (ไม่ควรใช้ `file://`)
4. ล็อกอินด้วยบัญชีที่กำหนดสิทธิ์แอดมิน
5. ลองสร้างหมวดหมู่และสินค้า 1 รายการ แล้วเปิด `products.html` เพื่อดูผล
6. นำเข้า `data/initial-products.csv` ผ่านหน้าแอดมิน **หลังจาก** ตั้งค่าฐานข้อมูลและล็อกอินแล้ว

## 5) อัปโหลดภาพสินค้า
- ที่หน้า `admin.html` → เพิ่ม/แก้ไขสินค้า → เลือกภาพ JPG, PNG หรือ WebP ไม่เกิน 5 MB
- ภาพจะอัปโหลดไปยัง Supabase Storage bucket `product-images` แล้วบันทึก public URL ในรายการสินค้า
- หรือใส่ URL ภาพ HTTPS ที่มีสิทธิ์ใช้งานได้โดยตรง
- ถ้าไม่มีภาพ ระบบจะลอง `images/<รหัสสินค้า>.jpg` (อัปโหลดไฟล์ไว้ในโฟลเดอร์ `images/` ของเว็บ) และแสดงภาพสำรองหากไม่พบ
- ภาพที่ลบออกจากรายการสินค้าจะ **ไม่ถูกลบออกจาก Storage โดยอัตโนมัติ** เพื่อป้องกันลบภาพที่ใช้ร่วมกัน เจ้าของร้านสามารถลบไฟล์ที่ไม่ใช้แล้วใน Supabase Storage ได้

## 6) นำเข้า CSV Shopee Affiliate
1. เปิดหน้าแอดมิน → **นำเข้า CSV** → เลือกไฟล์ CSV ที่ได้จาก Shopee Affiliate
2. ระบบอ่านคอลัมน์ `รหัสสินค้า`, `ชื่อสินค้า`, `ราคา`, `ขาย`, `ชื่อร้านค้า`, `ลิงก์สินค้า`, `ลิงก์ข้อเสนอ`
3. ระบบใช้ `ลิงก์ข้อเสนอ` เป็น Affiliate URL ก่อน หากไม่มีจึงใช้ `ลิงก์สินค้า`
4. กดยืนยัน ระบบจะเพิ่มสินค้าใหม่หรืออัปเดตรหัสสินค้าที่มีอยู่
5. **สำรองข้อมูลก่อนนำเข้า**: รายการซ้ำจะอัปเดตชื่อ ราคา ลิงก์ และข้อมูลร้าน; พยายามเก็บภาพ หมวดหมู่ สถานะ และการปักหมุดเดิมไว้
6. เลือกหมวดหมู่และอัปโหลดภาพให้สินค้าเพิ่มเติมจากหน้าแอดมิน

**ข้อควรทราบ:** ราคาจาก CSV เป็นข้อมูล ณ วันที่ส่งออก ไม่ใช่ราคาสดจาก Shopee และไม่มีการดึงรูปสินค้าจาก Shopee อัตโนมัติ

## 7) เผยแพร่ GitHub Pages (หลังทดสอบสำเร็จเท่านั้น)
1. สร้าง **Repository ใหม่** เช่น `Shopthai2026-PRO-TEST` อย่าเพิ่งเขียนทับ Repo เดิม
2. อัปโหลดไฟล์ทั้งหมดจาก ZIP (ต้องมี `index.html` อยู่ที่ root)
3. ใน GitHub → **Settings → Pages** เลือก Deploy from a branch, `main`, `/(root)` แล้ว Save
4. ใน Supabase → **Authentication → URL Configuration** เพิ่ม URL ทดสอบของ GitHub Pages ใน Redirect URLs และตั้ง Site URL ให้ถูกต้องสำหรับระบบ Auth
5. เปิดหน้าเว็บและทดสอบการอ่านสินค้า ล็อกอิน เพิ่มสินค้า อัปโหลดภาพ แก้ไข ลบ และ CSV
6. เมื่อตรวจสอบครบแล้ว ค่อยตัดสินใจว่าจะย้ายโปรเจกต์ไปใช้ Repository เดิมหรือไม่

## 8) ข้อควรระวังด้านความปลอดภัย
- RLS ป้องกันไม่ให้ผู้เยี่ยมชมทั่วไปแก้ไขข้อมูล; สิทธิ์แอดมินอ้างอิงตาราง `admin_users` ซึ่งเจ้าของโปรเจกต์เพิ่มผ่าน SQL Editor เท่านั้น
- อย่าปิด RLS และอย่าใส่ service_role key หรือรหัสผ่านในไฟล์เว็บไซต์
- Bucket ภาพเป็น **public**: อย่าอัปโหลดข้อมูลส่วนตัวหรือเอกสารลับ
- ใช้ HTTPS ใน production; URL สินค้าและรูปต้องเป็นแหล่งที่คุณเชื่อถือ
- สำรองฐานข้อมูลและรูปภาพเป็นระยะ; ตรวจสอบค่าบริการ/โควตาของ Supabase ตามแผนที่เลือก
- หน้าเว็บเรียก Supabase CDN ผ่านอินเทอร์เน็ต ต้องออนไลน์จึงทำงานได้
