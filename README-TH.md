# Shopthai2026-PRO — Patch 03: Affiliate Click Dashboard

## สิ่งที่ได้
- บันทึกคลิกปุ่มซื้อ Shopee ในหน้ารายการสินค้า หน้ารายละเอียด และรายการที่สนใจ
- Dashboard แอดมิน: วันนี้ / 7 วัน / 30 วัน และอันดับสินค้า 20 รายการใน 30 วัน
- ไม่บันทึก IP, cookie, user-agent หรือข้อมูลลูกค้าโดยตรง
- ไม่ต้องมี Edge Functions และไม่ต้องเปิดสิทธิ์ SELECT ของตารางคลิกให้บุคคลทั่วไป

## ขั้นตอนติดตั้ง (ยังไม่เปลี่ยนระบบจริงจนกว่าจะทำเอง)
1. สำรอง `admin.html` และ `assets/app.js` ที่ใช้งานอยู่ก่อน
2. ตรวจสอบว่า Supabase มี `products.shopee_id`, `products.name`, `products.is_active`, `products.affiliate_url` และ `admin_users.user_id` ตามไฟล์เดิม
3. เปิด Supabase SQL Editor ตรวจ SQL ใน `sql/01_click_tracking.sql` แล้วรันด้วยตนเอง (เป็นการเปลี่ยนฐานข้อมูลจริง)
4. นำ `admin.html` และ `assets/app.js` ไปแทนที่ไฟล์ชื่อเดียวกันใน branch ทดสอบของ GitHub; **อย่าแทนที่ `assets/config.js`**
5. ทดสอบคลิกปุ่มซื้อจากหน้าสินค้า แล้วล็อกอินแอดมิน เปิดหัวข้อ “สถิติคลิก” และกดรีเฟรช
6. ตรวจสอบ RLS/สิทธิ์ของ admin_users ตามที่ใช้งานจริงก่อน deploy production

## หมายเหตุสำคัญ
- สถิติเป็น click events ไม่ใช่ unique visitors, ยอดขาย หรือค่าคอมมิชชัน
- การบันทึกใช้ `fetch(..., keepalive:true)` จึงเป็น best-effort: บางคลิกอาจไม่ถูกนับจากเครือข่าย/เบราว์เซอร์
- RPC บันทึกคลิกเปิดให้ผู้เยี่ยมชมเรียกได้: มีความเสี่ยงคลิกปลอม/บอต; ต้องพิจารณา rate limiting / CAPTCHA / Edge Function เมื่อทราฟฟิกเพิ่ม
- ต้องติดตั้ง SQL ก่อนหน้าเว็บ มิฉะนั้นจะเห็นข้อผิดพลาดการโหลดสถิติ และคลิกจะไม่ถูกบันทึก
- ใช้ Supabase publishable/anon key ที่อยู่ใน `assets/config.js` เท่านั้น ห้ามใส่ service_role key ในเว็บ
- การเพิ่มข้อมูลคลิกมีค่าใช้จ่ายตามการใช้ฐานข้อมูล Supabase และอาจต้องลบข้อมูลเก่าเป็นระยะ
